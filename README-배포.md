# ONLY2012 배포 방법

동아(윤정미) 중2 5과·6과 전용 어법 앱. 이 폴더를 그대로 Vercel에 올리면 됩니다.

## 폴더 구성

| 파일 | 역할 |
|---|---|
| index.html | 앱 전체 (ONLY12에서 5·6과만 남겨 만든 것) |
| manifest.webmanifest | 휴대폰 "앱 설치"용 정보 (이름, 아이콘, 색) |
| sw.js | 오프라인에서도 열리게 하는 캐시 |
| icons/ | 앱 아이콘 (192, 512, 마스커블, 아이폰용) |
| vercel.json | 새 버전이 바로 반영되도록 캐시 설정 |
| _build/ | 다시 만들 때 쓰는 스크립트 (배포 안 됨) |

## 처음 배포 (한 번만)

1. https://vercel.com 에서 GitHub 계정으로 가입 (무료 Hobby 플랜).
2. 터미널(PowerShell)에서:
   ```
   npm i -g vercel
   cd C:\Users\luvta\ONLY2012
   vercel login
   vercel --prod
   ```
   - 질문이 나오면 모두 기본값(Enter). 프로젝트 이름은 `only2012`.
   - 끝나면 `https://only2012.vercel.app` 같은 주소가 나옵니다. 이름이 이미 쓰였으면 다른 주소가 나옵니다.
3. Vercel 대시보드 → 프로젝트 → **Analytics → Enable**.
   - 쿠키 없는 방문자 통계라 동의 팝업이 필요 없습니다.
   - 방문자 수, 페이지, 기기를 볼 수 있습니다.

## 학생 휴대폰에 설치

- **안드로이드(크롬):** 주소 접속 → 메뉴 ⋮ → **앱 설치** 또는 **홈 화면에 추가**
- **아이폰(사파리):** 주소 접속 → 공유 버튼 → **홈 화면에 추가**

설치하면 ONLY2012 아이콘이 생기고, 주소창 없이 앱처럼 열립니다.

## 수정 후 다시 배포

폴더 안 파일을 바꾼 뒤 `vercel --prod`만 다시 실행하면 됩니다. 학생들은 앱을 다시 열면 새 버전을 받습니다.

## 알아둘 점

- 학습 기록은 각 학생 기기(브라우저)에만 저장됩니다. 기기를 바꿀 때는 앱의 "기록 코드"로 옮깁니다.
- Vercel 무료 Hobby 플랜은 비상업용입니다. 나중에 유료화하면 Pro 플랜($20/월)으로 바꿔야 합니다.
