# ONLY2012

동아(윤정미) 중2 **5과·6과** 내신 영어 ‘어법상 틀린 것 고르기’를 이유까지 연습하는 앱.

👉 https://only2012.vercel.app

| Lesson | 문법 |
|---|---|
| 5과 | 목적격 관계대명사 · used to + 동사원형 |
| 6과 | 지각동사 · so ~ that / too ~ to · 실전 혼합 |

- 1분 루틴: 한 문장 카드 10장, O/X → 틀린 단어 짚기 → 이유
- 실전 모드: 5지선다
- 문장 듣기, 틀린 문장 → 맞는 문장 비교 듣기
- 가입 없이 별명만, 기록은 기기에 저장 (기록 코드로 기기 이동)
- 휴대폰 홈 화면에 설치 가능(PWA)
